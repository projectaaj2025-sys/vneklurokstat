# Правда или миф? — интерактивный урок

Урок-презентация по теории вероятностей для 10 класса: закон больших чисел,
математическое ожидание `M(X)`, дисперсия `D` и `σ`. Внутри 50 слайдов:
симуляторы монеты, опроса и рулетки, квизы с проверкой, комикс, рефлексия и итоги.

## QR-код внутри урока

В нижней панели есть кнопка **QR** — она автоматически строит код из адреса,
по которому открыт урок. Удобно вывести на проектор и дать классу открыть урок
на телефонах.

- `?qr` — открыть урок сразу с окном QR-кода;
- `?qrurl=https://example.com/...` — построить код для другой ссылки;
- в окне есть «Скопировать ссылку» и «Скачать PNG» (1024×1024);
- горячая клавиша `Q`, закрыть — `Esc`.

Код строится локально библиотекой
[qrcode-generator](https://github.com/kazuhikoarase/qrcode-generator) (MIT):
никаких внешних сервисов, запросов и интернета не требуется.
